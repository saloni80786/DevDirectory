# DevDirectory

DevDirectory - Engineering Portal built with React and Vite.

An engineering portal where team leads can discover developers, explore projects, read engineering bulletins, and publish updates.

## Tech Stack

- React
- React Router
- Vite
- Axios
- Express backend with JWT authentication

## Getting Started

Install dependencies:

```bash
npm run setup
```

Start the frontend and backend:

```bash
npm run dev:all
```

The frontend runs at `http://localhost:5173` and the API runs on port `5000`.

To run only the frontend:

```bash
npm install
npm run dev
```

## Environment Variables

Use the provided `.env.example` files as templates for your local environment configuration. Do not commit real secrets or `.env` files.
